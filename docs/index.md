# DocFrame Documentation

**Scope statement:** This doc set covers the DocFrame Python library only.

## What is DocFrame?

**Question:** *What does DocFrame provide?*

**Answer:** DocFrame extends Polars with document‑aware data frames and a `.text` namespace for common text operations (tokenization, counts, n‑grams, and more).
